BigDFT-Suite tutorial

This branch is created to better understand how BigDFT works and how to generate an input file, run an optimization or a dynamic simulation.
This is a work in progress guide so much of the informations are written as comments in inputfiles or into scripts.
To learn deepen how to run the software visit the original page https://l_sim.gitlab.io/bigdft-suite/index.html.

BigDFT and Suite version needs to work at the best with PyBigDFT. This program run as a Python library, it uses software and module contained in Suite to launch simulations and to visualize geometry input.
All scripts are runnable in their directory by typing "python script.py"

To build and merge both Big-DFT-Suite and LibNEGF, has been developed real_installer.sh.
The bash script compile and install by it self both software. The specifications could be found into installation_all/README.md.
